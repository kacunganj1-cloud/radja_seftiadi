RADJA SEFTIADI — WEBSITE PROFIL

ISI FOLDER
- index.html: halaman profil responsif, termasuk cerita pribadi Radja
- robots.txt: izin crawling mesin pencari
- sitemap.xml: peta situs awal
- assets/profile.jpg: letakkan foto profil di sini

SEBELUM DIPUBLIKASIKAN
1. Ganti semua teks GANTI-DENGAN-URL-WEBSITE-KAMU dengan URL website final.
2. Ganti Tautan TikTok sudah diisi: https://www.tiktok.com/@radjzstore1. Tambahkan akun lain hanya jika memang milikmu.
3. Buat folder assets dan masukkan foto profil sendiri dengan nama profile.jpg.
4. Pastikan semua informasi benar dan tautan aktif.

PUBLIKASI GRATIS
Bisa diunggah ke GitHub Pages atau layanan static hosting gratis. Setelah mendapat URL final, perbarui canonical, sitemap.xml, robots.txt, og:image dan JSON-LD di index.html.

GOOGLE
1. Tambahkan situs di https://search.google.com/search-console
2. Verifikasi kepemilikan situs.
3. Kirim sitemap.xml.
4. Gunakan URL Inspection untuk meminta pengindeksan halaman.
5. Tunggu proses crawling dan indexing. Tidak ada jaminan posisi atau Knowledge Panel.

PENTING
Website ini belum online dan belum terdaftar di Google. Jangan isi tautan akun atau klaim pencapaian yang tidak benar. Gunakan hanya foto dan akun milik sendiri.
